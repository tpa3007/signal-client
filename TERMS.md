# Terms

Signal Client is provided for research and educational use only. It is not
financial advice and does not execute trades.

Hosted full Signal + Forager runs execute on the author's private worker. The
client receives reports, not private source code or author data.

When a Signal author share endpoint is configured, the generated audit and
anonymized run report may be sent to that endpoint for product and model
improvement. The wallet address is excluded unless `--consent-wallet` is also
provided.
