# Signal Workflows

Эта папка содержит copy/paste команды для новых агентских чатов.

Главный файл:

- `MASTER_AGENT_COMMANDS_RU.md` - мастер-команды для discovery, deep dive, signal gate, learning, real manual trades, maintenance и daily brief.
- `SIGNAL_FORAGER_MASTER_COMMANDS_RU.md` - двухшаговые мастер-команды Signal -> Forager -> Signal, Forager-first experiment и общий learning loop.

Правило: любой новый агент сначала читает root operating contract, потом этот файл, и только после этого выполняет задачу.
