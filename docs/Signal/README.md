## Folder Map

- `core/` - north star, architecture, protocol, roadmap.
- `protocols/` - research engines, gates, lanes, learning logic, ledger rules.
- `manuals/` - operator manuals and higher-level workflow notes.
- `workflows/` - copy/paste master workflow commands for agents.
- `technical/` - integrations, dashboard brief, developer handoff, implementation-facing docs.
- `reports/` - dated research runs, audits, session logs, forward tests.
- `data/` - static supporting data and snapshots.

## Report Naming

New dated reports should go to `reports/`:

```text
YYYY-MM-DD - [Report Name] RU.md
```

New reusable workflow prompts should go to `workflows/`.
New architecture/protocol documents should go to `core/`, `protocols/`, or `technical/` depending on audience.

The project philosophy is:

> imaginative intake, strict pre-bet research, hold-to-resolution learning.

Moonshot Scout is allowed to be excited. Compounder research is allowed to be confident. The pre-bet checklist is not.
